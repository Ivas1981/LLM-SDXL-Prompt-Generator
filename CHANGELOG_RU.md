# История изменений

## [1.3.1] - 2026-09-02

### Изменено
- Удален тайминг по каждому шагу; выводится только общее время на один промпт
- Маркер модели в JSON теперь вставляется после последнего существующего промпта, а не в начало файла

## [1.3.0] - 2026-09-02

### Добавлено
- `prompts/step7_post_process.txt` для автоматического улучшения промпта после шага 7
- Автоматическая вставка маркера модели первой записью в JSON (`name` = модель, пустые `positive`/`negative`)
- Тайминг каждого шага и общее время генерации выводятся в консоль
- Пауза перед выходом в `main.py`

### Изменено
- После шага 7 сборка всегда дополняется пост-процессингом через локальную модель (без флага конфига)
- JSON выходной файл получает маркер модели в начало, если файл пуст или маркер отсутствует
- Тайминг батча и пайплайна выводится строками `[timing]`
- Консоль остаётся открытой до нажатия клавиши после завершения генерации

## [1.2.0] - 2026-09-02

### Добавлено
- Переключатель SFW/NSFW режима через `nsfw` в `config.toml` или env `NSFW`
- Промпт `step4_state_sfw.txt` для SFW режима (без поля `nudity`)
- Расширен `NEGATIVE_BASE_TAGS` стандартными SDXL артефактами (text, watermark, jpeg artifacts и т.д.)
- `pyproject.toml` с `python_requires = ">=3.11"` и опциональным `tomli` для py310
- `requests.compat.json` заменён на stdlib `json` в `core/lm_client.py`

### Изменено
- Исправлен дубль в README (удалены повторяющиеся буллеты)
- `config.toml.example` теперь содержит секцию `[generation]` с `nsfw` и `models_timeout`
- Базовый негативный промпт теперь покрывает распространённые SDXL артефакты по умолчанию
- Системные промпты переработаны по аудиту: `time_of_day` в step2 синхронизирован с `VALID_TIMES`, `eye_contact` в step3 исправлен на `"direct"`, step7 получил нейтральный SFW-пример и `step7_assemble_nsfw.txt` для NSFW, step4 SFW/NSFW ужесточены, step5/6/8 усилены

## [1.1.0] - 2026-09-02

### Добавлено
- Дедупликация тегов внутри поля и между полями в `core/validator.py`
- Логирование причин ретраев для ошибок шагов пайплайна, чат-ретраев и пропусков батча
- Встроенный дефолт `NEGATIVE_BASE_TAGS`, чтобы `negative_prompt` не был пустым
- Поддержка `models_timeout` в `config.toml` и через env `MODELS_TIMEOUT`
- Поддержка `uniqueness_threshold` в `config.toml` `[generation]` и через env `UNIQUENESS_THRESHOLD`

### Изменено
- Стриктерные правила для камеры/объективов в `prompts/step6_camera.txt`, чтобы не разбивать составные теги
- Промпт сборки (`prompts/step7_assemble.txt`) теперь требует, чтобы поле `camera` содержало только технические теги
- `README.md` и `README_RU.md` обновлены с новыми возможностями

### Исправлено
- `_clean_field()` больше не разбивает составные термины в prose-режиме
- Отладка больше не перезаписывает `debug.log` неожиданно
- Загрузка конфига теперь выводит OpenAI URL из нативного LM Studio URL, если `openai_url` отсутствует

## [1.0.0] - 2026-09-01

### Добавлено
- 8-шаговый LLM-пайплайн для генерации SDXL промптов
- Системные промпты строго в JSON со схемами для каждого шага
- Семантическая проверка дубликатов через эмбеддинги (`/v1/embeddings`)
- Автоматическое `reasoning="off"` для reasoning-моделей
- Пресеты сэмплирования в зависимости от архитектуры (Qwen, Gemma, Mistral, DeepSeek, Nemotron, GPT-OSS)
- Атомарная запись JSON с безопасным прерыванием по Ctrl+C
- Реестр переменных окружения (`env_registry.py`) с типизированным доступом
- Поддержка `config.toml` для настроек подключения LM Studio
- Функциональный набор unit-тестов (73 теста)

### Исправлено
- Относительные импорты в `main.py` для запуска напрямую
- Ошибка в `_format_user_hint`, где `{names}` конфликтовал с `str.format()`
- Отдельный список `FORBIDDEN_TAGS_NEGATIVE`, чтобы негативный промпт не терял теги
- Расширены regex-паттерны в consistency-валидации для `nighttime`, `rainy`, `sunny`, `golden hour`
- Нормализация ключа архитектуры в model info (`qwen3-vl` → `qwen3vl`)
- Обработка коллизий имён на шаге 8 с ретраем и числовым суффиксом
- Прогресс-колбэк теперь показывает реальные `added` и `attempts`
- Выгрузка моделей LM Studio использует реальный `instance_id`

### Изменено
- Миграция с монолитного скрипта на модульный пакет `core/`
- Сборка позитивного/негативного промптов централизована в `core/validator.py`
- Quality-bait теги удаляются до сохранения
