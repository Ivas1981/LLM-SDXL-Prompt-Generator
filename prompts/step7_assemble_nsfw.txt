Assemble the previous steps into a single JSON object for Stable Diffusion XL.
Use only these exact keys:

{
  "subject": "<literally {prompt} followed by clothing tags only, 4-10 words>",
  "pose": "<body position, expression, eye contact only, 5-10 words>",
  "state": "<physical condition and nudity-related state, 6-12 words>",
  "environment": "<location, time, weather, props only, 8-15 words>",
  "relationships": "<spatial layout only: subject vs environment, foreground/background, 6-14 words>",
  "lighting": "<physical lighting only, 5-10 words>",
  "camera": "<camera body, lens, angle, optical quality only, 6-12 words>"
}

Rules:
- The string "{prompt}" (with braces) MUST appear verbatim in the "subject" field. It is a placeholder for appearance.
- Do NOT replace {prompt}. Do NOT describe hair, skin, age, or ethnicity.
- Use only English.
- Each field MUST be comma-separated tags only. NO full sentences. NO periods.
- Preserve compound terms as single tags. Examples: "Canon EOS R5", "24-70mm f/2.8L", "full-frame sensor", "low angle", "shallow depth of field", "shirtless torso".
- Do not repeat the same concept across fields. Examples: do not put "direct eye contact" in both pose and relationships; do not put lighting words into environment; do not put pose into subject.
- subject = "{prompt}" + clothing tags only (remaining clothes, if any).
- pose = body position + expression + eye contact only.
- state = physical/emotional condition + natural scene-motivated partial or full nudity tags.
- environment = location + time + weather + props only.
- relationships = spatial relations only.
- camera = technical camera/lens/angle/quality only. No people, actions, or scene content.
- Nudity must stay in the state field (and optionally implied by sparse clothing in subject). Keep it diegetic, not a pure fetish list.
- Do NOT use quality-bait tags: "masterpiece", "best quality", "8k", "ultra detailed", "HDR", "UHD".
- Keep tags concise and distinct.
- Output only the JSON object, nothing else.
