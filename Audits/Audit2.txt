### Оставшиеся / новые замечания

1. **STEP_USER_HINT для step4 не переключается**  
   В `pipeline.py` user-hint по-прежнему жёстко:
   ```text
   "Describe a natural way the scene includes partial or full nudity."
   ```
   Даже в SFW-режиме LLM получает этот hint (system-prompt меняется, user — нет).  
   **Рекомендация:** сделать два hint’а или условно:
   ```python
   "step4_state.txt": (
       "... partial or full nudity." if NSFW
       else "... physical state and expression (no nudity)."
   ),
   ```

2. **Документация vs код**  
   - В README таблице env-переменных **нет** `NSFW`.  
   - В Notes всё ещё написано «Negative prompt starts empty…» — это уже не так (есть полноценный `NEGATIVE_BASE`).  
   - В Features нет упоминания SFW/NSFW toggle.

3. **`config.toml.example` и `config_loader`**  
   Нужно убедиться, что `resolve_nsfw()` корректно читает и env, и `[generation].nsfw`.  
   (По коду выглядит, что да, но стоит явно проверить edge-cases: `"true"/"1"/"yes"` vs `"false"`.)

4. **SFW-prompt и сборка**  
   В SFW `step4_state_sfw.txt` отдаёт только поле `state`.  
   В `run_pipeline` есть fallback:
   ```python
   "state": cleaned_parsed.get("state") or cleaned_parsed.get("nudity") or "",
   ```
   Это работает, но в SFW-режиме поле `nudity` вообще не должно появляться. Можно явно игнорировать `nudity`, когда `not NSFW`.

5. **Версия**  
   `pyproject.toml` всё ещё `version = "1.1.0"`, а CHANGELOG уже `1.2.0`. Лучше синхронизировать.

6. **Мелочи**  
   - В CHANGELOG 1.2.0 повторно перечислены фиксы, которые уже были в 1.1.0 (`_clean_field`, debug.log, openai_url). Лучше убрать дубли.  
   - `Audits/Audit1.txt` (мой предыдущий аудит) теперь лежит в репозитории — ок, если это намеренно.
